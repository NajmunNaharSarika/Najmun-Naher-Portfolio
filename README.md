# Najmun Naher - Modern Developer Portfolio 🌟

A modern, responsive personal portfolio website built with **Next.js (App Router)**, **Tailwind CSS**, **Framer Motion**, and **React Icons**.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

---

## 🎨 Features & Architecture

- **Next.js 14 (App Router)** & **TypeScript**
- **Sleek Dark/Light Mode Switch** (powered by `next-themes`)
- **Framer Motion** smooth scroll animations, stagger reveals, and interactive hover effects
- **Clickable Direct Actions**:
  - Direct Phone Call (`tel:+8801723471104`)
  - Direct WhatsApp Chat (`https://wa.me/8801723471104`)
  - Email link & verified contact buttons
- **Interactive Google Maps Embed** for *Azimpur, Dhaka 1205*
- **Dedicated Profile Container** with Next.js `<Image />` and glowing gradient frames
- **8 GitHub Project Cards** with category filter pills, tech stack badges, and direct repository links
- **Academic & Specialized Training Timeline** featuring *IsDB-BISEW IT Scholarship Programme* & *Creative IT Institute*
- **Centralized Data**: All profile info, skills, education, and project details are structured cleanly in `data/resumeData.json`

## 🌐 Deploy to Vercel (Free Hosting)

1. Push your repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: modern portfolio"
   git branch -M main
   git remote add origin https://github.com/NajmunNaharSarika/<repo-name>.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New Project"** -> **"Import"** your portfolio repository.
4. Click **"Deploy"** (Vercel automatically detects Next.js with zero configuration needed).
